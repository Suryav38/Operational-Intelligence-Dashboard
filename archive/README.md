# Archive

Kept for reproducibility and history. Not loaded by the app and not searched by the AI assistants.

- `documents/`: prototype notes from earlier versions (guidelines, planning reviews, route-change notices and tool notes, each
  headed "ARCHIVED PROTOTYPE NOTE"), plus the 2027 EUV pilot-introduction note from the retired pilot study. Their counts and
  loadings predate the current model and would mislead retrieval.
- `code/`: presentation modules from earlier versions (`performance_charts.py`, `launch_charts.py`) that no view uses.

The simulation sources stay in `code/` (`fab_flow.py`, `fab_sim.py`, `generate_fab_demo.py`, `simulate_q4_to_date.py`,
`make_tool_logs.py`) so every table and note can be regenerated.
